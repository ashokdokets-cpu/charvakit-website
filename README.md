# Charvakit - Company Website

Modern website for Charvakit Private Limited, showcasing our digital solutions and products including Dokets VouchAI.

## Tech Stack

- **Backend:** Python FastAPI
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
- **Hosting:** Render
- **CI/CD:** GitHub Actions

## Products

### Dokets VouchAI
AI-powered escrow platform with:
- 1% Transaction Fee
- WhatsApp Integration
- 34 Languages Support
- 13 Currencies
- AI-Powered Dispute Resolution
- Website: [dokets.com](https://dokets.com)
