Controls which incoming JDs reach your dashboard. Tune here without code changes.

Skill Overlap Threshold

Minimum % of JD-required skills that must match a bench candidate. Lower = more jobs pass (more noise). Higher = fewer jobs pass (more precise).

30%

Recommended: 30% (default). Lower to 20% if too many jobs rejected. Higher to 50% if too many irrelevant jobs pass.

Log Rejected JDs

When enabled, every rejected JD is written to charvak_rejected_jds for audit. Disable to reduce DB writes (loses visibility into what was filtered).

Audit Retention

How many days to keep rejected JDs in the audit table before auto-purge. Session 108C (retention engine) will use this value.

days
How this works:
• Every incoming JD (email or API) passes through the filter.
• Gate 1: Must be US, Canada, or remote/worldwide location.
• Gate 2: Visa must be compatible with at least one bench candidate (H1B/OPT/H4-EAD).
• Gate 3: Skill overlap must be ≥ threshold above.
• Rate is NOT a gate — it's used only for scoring, never rejection.
• Rejected JDs go to /admin/rejected-jds for audit.
