What is "AI slop" in code?

AI slop is the low-quality code that AI code generators (Copilot, ChatGPT, Cursor, Claude) produce when they prioritize plausibility over correctness. It compiles, it looks reasonable, and it ships — but it carries anti-patterns that compound into real technical debt.

Common AI slop patterns

  • Dead code — functions that are defined but never called, variables that are set but never read
  • Unused imports — the AI optimistically imports things "just in case"
  • Redundant wrappers — a function whose only job is to call another function with the same args
  • Excessive comments — TODO markers, redundant JSDoc, over-explanation of obvious lines
  • Over-engineering — abstractions for problems that don't exist yet
  • Magic numbers — unexplained constants scattered through the code
  • Missing error handling — the "happy path only" pattern
  • Duplicate logic — the same check written three different ways

Why is it a problem?

AI slop costs money. Every line of dead code you review, every unused import you maintain, every redundant wrapper you refactor — that's engineering time you're paying for. As codebases grow, slop compounds faster than clean code.
